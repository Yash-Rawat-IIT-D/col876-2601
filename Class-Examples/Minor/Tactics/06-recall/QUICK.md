# Quick decision sheet

Read the goal and local hypotheses in InfoView. Choose a structural first move.

| You see | First move | Then |
|---|---|---|
| `⊢ ∀ x, ...` or `⊢ P → Q` | `intro` | Work with the new variable/hypothesis. |
| `h : P`, `⊢ P` | `exact h` / `assumption` | Goal closes. |
| `h : P → Q`, `⊢ Q` | `apply h` | Prove `P`. |
| `⊢ P ∧ Q` or `⊢ P ↔ Q` | `constructor` / `refine` | Prove every resulting goal. |
| `h : P ∧ Q` | `h.left`, `h.right`, `rcases` | Use the needed component. |
| `⊢ P ∨ Q` | `left` / `right` | Choose a provable side. |
| `h : P ∨ Q` | `cases h` | Cover both alternatives. |
| `⊢ ∃ x, P x` | `exists witness` | Prove property of that witness. |
| `h : ∃ x, P x` | `obtain ⟨x,hx⟩ := h` | Use witness and evidence. |
| `⊢ ¬P` | `intro hP` | Derive `False`. |
| Goal computes | `rfl` | If not, identify the missing theorem/rewrite. |
| Known equality applies | `rw [h]` or `rw [← h]` | Add `at hyp` to edit a hypothesis. |
| Definitions clutter goal | `unfold f`, `change`, or `simp [f]` | Inspect the simplified goal. |
| Finite variants or one final proof rule | `cases` | Constructor cases, no IH. |
| Recursive data or derivation | `induction` | Name all IHs; trees have two. |
| Accumulator changes on recursion | `induction xs generalizing acc` | State a theorem valid at every accumulator. |
| Match/if blocks progress | `split` or `split at h` | Prove each branch. |
| Simple arithmetic/order | `grind`; `omega` if Mathlib available | Choose induction/invariant first if required. |
| Polynomial identity | `ring` with Mathlib | Rewrite hypotheses separately. |
| Multi-step equality/order | `calc` | Justify each step. |

**Tactic composition:** `t₁ <;> t₂` sends `t₂` to all subgoals generated by `t₁`; `repeat'` walks generated goals; `first` tries alternatives in order; `try` allows a tactic to fail without stopping the script. Use these after you know the goal shapes.

**Three proof reminders:** `cases` does not provide an IH. `simp at *` can leave a goal. `sorry` and an arbitrary `axiom` do not demonstrate a checked proof of the intended statement.
